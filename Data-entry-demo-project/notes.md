[Data Entry Practice Project](https://azharulrafy.com/data-entry-projects)

Practice project based on Azharul Rafy's "Data Entry Practice Projects" brief — a set of sample tasks designed to demonstrate common data entry skills for a portfolio.

What this covers

Two of the brief's demo tasks, completed to build a data entry portfolio sample:

1. Scanned Document → Word Transcription

Transcribed two scanned document pages into clean, formatted Word files:

Sharing Gallup Student Poll Results — guidelines and methodology notes for a student poll program, transcribed from a scanned appendix page into Word with headings and bullet points preserved.
Speak Up Survey: SIATech Network Consolidated Reports — a multi-state school directory (California, Arkansas, Florida) with program types, transcribed into Word with the original table structure preserved.

Tools: Microsoft Word, manual transcription from scanned PDF source.

2. PDF → Excel Data Extraction

Converted a scanned membership directory (Estate Planning Council of Cleveland) into a structured Excel spreadsheet — splitting names, titles, companies, and contact details into separate columns (Name, Title, Company, Street Address, City, State, ZIP, Phone, Fax, Email, Website).

Tools: Microsoft Excel, manual data extraction and formatting from scanned PDF source.

3. Online Research → Spreadsheet Compilation

Researched and compiled contact information for 20 New York City restaurants into a spreadsheet, including website, address, phone number, email, and review count for each.

Tools: Microsoft Excel, online/web research (manual, not automated scraping).
