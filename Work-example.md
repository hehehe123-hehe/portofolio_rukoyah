## 🏠 Financial Administration — Home Renovation Project
**Role:** Financial Administrator (freelance)

Managed the full financial tracking for a home renovation project using a custom-built Excel workbook.

- Built a 3-sheet Excel workbook to log, categorize, and reconcile every transaction throughout the project
- Maintained an accurate running summary so spending could be checked against budget at any point
- Delivered a clear, auditable record the client could review without needing to interpret raw data

**Tools:** Microsoft Excel (formulas, multi-sheet linking, summary reporting)
